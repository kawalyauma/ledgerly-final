# Name-only attendance kiosk

The attendance kiosk intentionally uses a single capture flow:

1. Choose Arriving or Leaving.
2. Search the school directory by name, admission number or staff number.
3. Select the correct profile.
4. Confirm the attendance event.

The kiosk does not initialize or use face recognition, face enrollment, QR scanning or NFC attendance capture. Events continue to use Ledgerly's supervised `MANUAL` attendance method so offline queueing, audit history, synchronization, kiosk lock mode, the idle live display and employee PIN unlock remain compatible.
